# RESET EXPLODE para Linux

Versão não oficial do [RESET EXPLODE](https://github.com/GustavoReset/ResetExplode) (de Gustavo, MIT) para Linux, com foco em Bazzite.

## Como instalar
```bash
tar -xzf resetexplode-linux-x64-*.tar.gz
cd resetexplode-linux-x64-*
./instalar.sh
```
Depois abra **RESET EXPLODE** no menu. Na primeira vez o app pede as permissões (uma vez). Detalhes e como desfazer no `README.md` do pacote.

Confira a integridade com `sha256sum -c resetexplode-linux-x64-*.tar.gz.sha256`.

## O que tem
Visão geral, Sistema, Sensores, Placa de vídeo AMD, Stress de CPU e RAM, Bench de CPU e a tela de permissões.
